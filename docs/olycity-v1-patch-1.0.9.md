# OLYCITY V1 — hotfix 1.0.9

Retrait de Rats 8.1.3, responsable du crash RatRaidCropsGoal. Le hotfix adapte la quête de Liam en conservant ses identifiants et récompenses, actualise les pages du carnet et retire les tables de butin Rats. Aucun autre mod retiré.

Serveur : sauvegarder, arrêter, puis exécuter sh olycity-update.sh 1.0.9 --serveur-arrete dans le dossier serveur, avec Java 17. Redémarrer ensuite.

Joueurs : fermer Minecraft puis relancer la même instance Prism. Les objets, blocs et créatures du mod Rats disparaîtront ; sauvegarder le monde avant la mise à jour. Les rats de Caverns & Chasms appartiennent à un autre mod et restent présents.
