# OLYCITY V1 — Modpack Minecraft

Le pack Minecraft du Discord OLYCITY, à importer dans CurseForge ou Prism Launcher.

- Minecraft Java 1.20.1, Forge 47.4.10, Java 17.
- 156 JAR inclus, dont Essential pour jouer dans le monde d’un ami.
- Configurations, quêtes, objets OLYCITY, ressources et shaders inclus.
- Shaders facultatifs ; commencer avec 8 Go de mémoire allouée si le PC le permet.

Le fichier fourni est conservé à l’identique : **OLYCITY-PACK-Test-Mathis.zip** (1 206 308 981 octets). Le nom affiché sur le site est OLYCITY V1 ; le manifeste interne reste `2026.10.07-test-essential`.

Il s’agit d’une **version de test**. L’intégration au site est testée ; l’import dans un launcher et la session multijoueur ne sont pas validés par ces tests.

Le guide d’installation est accessible sur https://games.olycity.fr/#modpacks.

SHA-256 : `357c1abfeb1c2a2fdc574ec55c99fe949edf96eb7391a324d73cb751d922a97b`

La taille du ZIP impose une pièce jointe de release GitHub : ne pas l’ajouter au dépôt Git ni à l’artefact Pages. Publier la release `olycity-v1` avec cette archive avant de déployer le lien de téléchargement.
