Installer le pack et jouer ensemble

Installation avec Prism Launcher

  1. Installe Prism Launcher et connecte ton compte Microsoft possédant Minecraft Java.
  2. Télécharge le ZIP Prism OLYCITY V1 ci-dessus, sans le décompresser. Le ZIP serveur est réservé à Romain.
  3. Dans Prism, clique sur Ajouter une instance → Importer, sélectionne ce ZIP, puis confirme l’import. Garde ton ancienne instance si tu en avais déjà une.
  4. Dans Modifier l’instance, vérifie Minecraft 1.20.1, Forge 47.4.10 et Java 17. La mémoire maximale est réglée à 8192 Mio (8 Go) : adapte-la à ton PC.
  5. Si Prism demande d’autoriser la commande avant lancement, autorise celle de cette instance : elle utilise Packwiz pour synchroniser le pack OLYCITY. Laisse-la activée.
  6. Clique sur Jouer et laisse le premier téléchargement d’environ 1,2 Go se terminer. Aux prochains lancements, les correctifs publiés sont récupérés automatiquement.

Les sauvegardes, touches, repères et réglages personnels exclus de la synchronisation restent à toi. Les configurations de gameplay du pack sont gérées. Pour recevoir un correctif quand tu es déjà en jeu, ferme Minecraft puis relance cette même instance.

Rejoindre le serveur OLYCITY

  1. Chacun utilise l’instance Prism OLYCITY avec les mises à jour activées et son compte Minecraft Java.
  2. Dans Minecraft, ouvre Multijoueur → Ajouter un serveur.
  3. Utilise l’adresse et le port communiqués par Romain.

Pour Romain : le ZIP serveur complet est prévu pour Linux, Docker et Crafty Controller. Les mises à jour serveur se font volontairement, serveur arrêté, vers la version indiquée.
